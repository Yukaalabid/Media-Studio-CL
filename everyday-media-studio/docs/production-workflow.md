# Production Workflow

1. **Topic selection** — choose a question tied to one editorial pillar.
2. **Research** — collect reputable sources and record what each source supports.
3. **Angle** — define one central idea and one takeaway.
4. **Script** — write hook, situation, explanation, insight, and engagement prompt for a 40–60 second video (50-second default). Read the voice-over aloud and time it.
5. **Storyboard** — define scene order, timing, on-screen text, visual metaphor, and sound cues. Confirm the complete timeline is 40–60 seconds.
6. **Asset preparation** — gather original or properly licensed visuals, icons, and audio. Track attribution/licensing.
7. **Remotion build** — use shared tokens and reusable components. Keep content data separate from visual code.
8. **Preview** — watch the full 40–60 second composition at normal speed and check text safe areas.
9. **Quality check** — review spelling, factual claims, transitions, audio levels, pacing, and brand consistency.
10. **Render** — export MP4 and inspect the actual output file.
11. **Publish** — add concise caption and relevant disclosure where applicable. No affiliate promotion in the first-month brand phase unless the owner changes the plan.
12. **Evaluate** — log metrics and learnings without overreacting to one post.
