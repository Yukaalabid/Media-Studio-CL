# Video Duration Standard

This project uses a mandatory duration range of **40–60 seconds** for standard short-form videos. The default production target is **50 seconds**.

## Frame mapping at 30 fps
| Runtime | Frames |
|---:|---:|
| 40 seconds | 1200 |
| 45 seconds | 1350 |
| 50 seconds | 1500 |
| 55 seconds | 1650 |
| 60 seconds | 1800 |

## Rules
1. Do not deliver a standard video shorter than 40 seconds or longer than 60 seconds unless the project owner explicitly approves an exception.
2. Target 50 seconds when no specific duration is given.
3. Time the final voice-over read aloud at a natural pace. Word count is only an estimate.
4. Do not add filler, repetition, or unnecessary pauses to reach the minimum. Add meaningful context, an example, an explanation, or an insight instead.
5. Whenever a duration changes, synchronize the Remotion composition length, scene frame ranges, video data, script timecodes, storyboard, and rendering guide.
